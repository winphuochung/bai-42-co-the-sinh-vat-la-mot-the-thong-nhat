# Web/app học tập — Khoa học tự nhiên 7, Bài 42

**Bài 42: Cơ thể sinh vật là một thể thống nhất**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.
Chương IX: Sinh sản ở sinh vật · SGK trang 173–174 · Tuần 32 – Tiết 130.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng: Các hệ cơ quan phối hợp khi vận động — chọn mức hoạt động (Nghỉ ngơi / Đi bộ / Chạy nhanh) để xem nhịp tim, nhịp thở và nhu cầu năng lượng thay đổi, kèm hình minh họa SVG thay đổi theo từng mức.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai42.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — mã Apps Script Web App ghi điểm về Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (đăng nhập, nền chính, hero) + logo giáo viên.
